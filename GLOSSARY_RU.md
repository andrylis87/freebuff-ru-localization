# Глоссарий русской локализации Freebuff (ru-RU)

Единый справочник терминов для каталога `cli/src/i18n/locales/ru.ts`.
Любая новая строка обязана следовать этому файлу; если термина здесь нет —
добавьте его в тот же PR, а не придумывайте перевод на месте.

Правила, из которых вытекает таблица:

1. **Переводится только то, что видит пользователь**: подписи, кнопки, меню,
   диалоги, подсказки, сообщения об ошибках, системные уведомления.
2. **Не переводится**: код, идентификаторы, имена файлов, пути, URL,
   CLI-команды и их алиасы, имена моделей и провайдеров, бренды, ключи API,
   технические логи, строки для разработчиков, содержимое `SKILL.md`
   (это контент проекта, а не интерфейс).
3. **Плейсхолдеры и разметка копируются буквально**: `{name}`, `{{name}}`,
   `%s`, `%d`, `${...}`, HTML-теги, Markdown, экранирование, переносы строк.
   Имя плейсхолдера на русском не меняется — меняется только текст вокруг.
4. **Множественное число** задаётся четырьмя формами
   `key.one` / `key.few` / `key.many` / `key.other` и выбирается через
   `Intl.PluralRules('ru')`: 1 файл, 2 файла, 5 файлов, 1,5 файла.
5. **Типографика**: пишем «ё» полностью («часто», «ещё»), кавычки `«…»`,
   тире `—` (с пробелами), многоточие `…` одним символом. Сокращения клавиш
   (`Ctrl+C`, `Esc`, `Enter`, `Tab`) остаются как есть.

| Термин                                                      | Почему                                                                           |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Freebuff, Codebuff, Freebucks                               | Бренды и названия продуктов                                                      |

| `bash`, `Enter`, `Esc`, `Ctrl+C`, `Ctrl+V`, `Tab`           | Имена команд и клавиш: их нельзя переводить, иначе инструкция перестаёт работать |

## Соглашения по коду

- Английский текст живёт **на месте вызова** как fallback:
  `t('help.title', 'Keyboard shortcuts')`. Каталог `ru.ts` хранит только
  русские переопределения, поэтому отсутствующий ключ автоматически
  отдаёт английский — пустых строк и «сырых» ключей в UI не бывает.
- Ключи — плоские, точечные, в нижнем регистре: `раздел.подраздел.поле`.
  Семейства: `cmd.*`, `help.*`, `input.mode.*`, `login.*`, `status.*`,
  `toast.*`, `queue.*`, `copy.*`, `lang.*`, `feedback.*`, `proposal.*`.
- Русский текст обязан содержать кирилицу — проверка
  `i18n/__tests__/locale-catalog.test.ts` ловит случайно скопированный
  английский оригинал.
- Числа и даты в новых строках форматируются через `Intl`
  (`formatNumber`, `formatDate`); счётчики во множественном числе —
  через `tp()`, который подставляет `{count}` в локальном виде
  (`1 234 сообщения`, `1,5 файла`).
